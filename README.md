A complete story in exactly six words, for the make.fun bounty [Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410). The program (`main.ts`, Node 22, standard library only) writes the story to `/output/entry.txt`:

> She kept his letter. Never read.

She kept it — but never read it. The contradiction is the story: a letter kept for years, unread, says everything about what was lost and what could not be faced. Every word earns its place, and what the letter says is left for the reader to fill in.

## Run it

```sh
node main.ts
```
